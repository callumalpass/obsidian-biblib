# BibLib 1.9.1

## Fixed

- (#50) Fixed citekeys ignoring fields edited in the create literature note modal after a lookup
  - A citekey generated by a DOI/URL/ISBN lookup, a Zotero Connector import or the "Regenerate citekey" button is now regenerated on submit if the form has changed, so a manually entered author or year is used
  - A citekey you typed yourself is never replaced, and "Use Zotero keys" still keeps the key from the lookup or import
  - Thanks to @bepolymathe for reporting
